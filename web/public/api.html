Documentación de la API
Endpoints públicos para consultar las tasas del dólar oficial y paralelo en Venezuela.
🔗 Endpoints disponibles
Endpoint Descripción Método
/api/v1/tasas/oficial Tasa oficial del BCV más reciente. GET
/api/v1/tasas/paralelo Tasa del dólar paralelo más reciente. GET
/api/v1/tasas/todas Todas las tasas disponibles con proveedor. GET
/api/v1/brecha Brecha porcentual entre paralelo y oficial. GET
/api/v1/proveedores Estado y fuente de cada proveedor activo. GET
📦 Ejemplo de respuesta 
{

    "tasa": 876.7976,

    "moneda": "USD/VES",

    "proveedor": "DolarAPI",

    "actualizado": "2026-10-26T14:30:00Z",

    "fuente": "BCV",

    "estado": "operativa"

}
⚡ Rate limiting y uso
  • Los endpoints son públicos y no requieren autenticación.
  • Límite: 60 solicitudes por minuto por IP.
  • Las tasas se actualizan cada 15 minutos mediante sincronización silenciosa.
  • Usa el encabezado Accept: application/json para respuestas JSON.
  • Los datos son de referencia pública; no son asesoría financiera.

Cómo compilar
Proyecto Android con Gradle wrapper. JDK 21, AGP 9.4 y Android Studio con soporte a AGP 9.

Android Studio (recomendado)

  1. Abre la carpeta del proyecto (File ▸ Open).
  2. Espera la sincronización (Gradle 9.6.0).
  3. Ejecuta la configuración app.
Requiere Android Studio que soporte AGP 9.4 y JDK 21.

Línea de comandos

cp local.properties.example local.properties
./gradlew :app:assembleDebug           # APK de depuración
./gradlew testDebugUnitTest            # Tests JVM
./gradlew :app:assembleRelease         # Release con R8 y shrinkResources
Tamaños y notas
  • APK debug: 21,9 MB
  • APK release: 2,40 MB con R8 y shrinkResources
  • Compilado con JDK 21, plataforma android-37.0 y build-tools 37.0.0
  • compileSdk 37 / targetSdk 37 / minSdk 31

Preguntas frecuentes
Todo lo que necesitas saber sobre DivTrack, las tasas del dólar y el uso de la app.
¿Qué es DivTrack? ▼
DivTrack es una app Android nativa para rastrear en tiempo real el dólar oficial (BCV) y el dólar paralelo en Venezuela, y convertir bolívares y dólares en ambos sentidos sin impuestos añadidos.
¿De dónde sacan las tasas? ▼
Usamos cuatro proveedores: DolarAPI, Yadio, ExchangeRate-API y DolarVZLA. La app consulta varios y se queda con el dato más fresco y válido.
¿Funciona sin internet? ▼
Sí. DivTrack usa arquitectura online-first: Room es la fuente de verdad local. Al abrir, ves el último dato guardado mientras se sincroniza en segundo plano.
¿Cómo instalo el APK? ▼
Descarga el APK desde GitHub Releases. Desde Android 8 necesitas activar "Instalar apps desconocidas" para el navegador o gestor de archivos.
¿Hay versión para iOS? ▼
Actualmente DivTrack solo está disponible para Android (Kotlin + Jetpack Compose). No hay versión para iOS en este momento.
¿La calculadora cobra impuestos? ▼
No. La conversión es directa: dólares a bolívares y viceversa, sin impuestos ni cargos añadidos.
¿Con qué frecuencia se actualizan las tasas? ▼
La sincronización silenciosa se puede configurar cada 15, 30, 60, 120 o 240 minutos desde Ajustes. También puedes hacer pull-to-refresh manual.
¿Es código abierto? ▼
El código está disponible en GitHub para revisión. La licencia de código aún no está definida; la tipografía Manrope usa SIL OFL 1.1.

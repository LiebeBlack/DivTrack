Stack tecnológico (2026)
Clean Architecture modular, MVI estricto, Kotlin 100 % y Jetpack Compose con Material 3.

App y UI

  • Kotlin 2.4.20
  • Jetpack Compose + Material 3
  • Navigation 3 (Nav3)
  • Hilt 2.60.1 (DI)
  • MVI estricto por pantalla

Datos y red

  • Retrofit 3.0.0 / OkHttp 5.5.0
  • Room 2.8.5 (base local)
  • DataStore Preferences
  • WorkManager 2.12.0 (sync)
  • kotlinx.serialization

Proveedores de tasas

  • DolarAPI (oficial y paralelo)
  • Yadio (paralelo con hora)
  • ExchangeRate-API (oficial BCV)
  • DolarVZLA (oficial, CDN)
  • Circuit breaker + frescura

Build y CI

  • AGP 9.4.0 / Gradle 9.6.0
  • JDK 21 (Temurin)
  • compileSdk 37 / minSdk 31
  • R8 + shrinkResources
  • GitHub Actions
📐 Dirección de dependencias
:app ─▶ :presentation ─▶ :domain ◀─ :data ─▶ :core:{network, database, datastore}
                    └──▶ :core:common (base pura para todos)
:domain no ve Android, Compose, Retrofit ni Room. Arquitectura limpia y capas desacopladas.
